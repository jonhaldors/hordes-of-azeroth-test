# Hordes of Azeroth test builds

Test releases of [Hordes of Azeroth](https://github.com/jonhaldors/hordes-of-azeroth), used to check builds before they go out. They can be unfinished or broken. To play, install from the main repository instead.

The source code for every build here is available under the same licences as the main repository (GPL-3.0 for the game, GPL-2.0 for the server). Ask in the main repository's issues for the source of any build.
